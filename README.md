Визуальный конструктор пользовательских процедур на базе Blockly с поддержкой мультитенантности, CQRS и асинхронного выполнения через Apache Kafka.

Запуск проекта
Требования: Java 17+, Docker, Docker Compose, Node.js 20+.
Запуск серверной части:
1. Собрать проект:
  .\gradlew clean bootJar -x test
2. Запустить сервисы:
  docker-compose up -d –build
3. Дождаться запуска всех контейнеров (примерно 2–3 минуты).

Запуск клиентской части:
1. Перейти в каталог frontend-приложения:
  cd blockly-frontend
2. Установить зависимости (при первом запуске):
  npm install
3. Запустить приложение:
  npm run dev
После запуска пользовательский интерфейс будет доступен по адресу:
http://localhost:5173

Подключение к базе данных
PostgreSQL доступен со следующими параметрами:
•	URL: jdbc:postgresql://localhost:5433/blockly
•	База данных: blockly
•	Пользователь: blockly
•	Пароль: blocklypwd

Работа с системой
1. Открыть http://localhost:5173.
  Логин: user_appliner или user_google (разные тенанты)
  Пароль: testpass
2. Создать процедуру в визуальном редакторе Blockly, или загрузить готовую(Мои процедуры).
3. Выполнить процедуру через интерфейс приложения.
4. Выполнение осуществляется асинхронно через Kafka.
5. Результат отображается в пользовательском интерфейсе после завершения обработки.

Остановка
docker-compose down
